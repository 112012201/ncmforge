## 零、本轮：编码降级梯 + 品牌 + 开源准备

### 0.1 编码降级梯（重新编码时生效）

按你指定的优先级逐档尝试，**实测探测**本机 ffmpeg 支持哪些编码器，失败一档降一档：

```
Dolby TrueHD → E-AC-3 (DD+) → DTS → FLAC → ALAC → Opus → WavPack → AAC-LC (MP4) → MP3
```

| 编码 | 实测声道上限 | 说明 |
|---|---|---|
| Dolby TrueHD | **6** | ffmpeg 的 TrueHD 编码器超过 6 声道**直接报错** |
| E-AC-3 (DD+) | **6** | ffmpeg 无法写 Atmos 对象元数据，所以是 DD+ 而非真 Atmos |
| DTS | **6** | ffmpeg **没有** DTS-HD MA 编码器，`dca` 产出的是有损 DTS 核心 |
| FLAC | 8 | 规范上限 |
| ALAC | 8 | 实测 12 声道时会静默变成 7 声道 |
| Opus | 8 | 标准声道映射上限 |
| **WavPack** | **16** | **本表中唯一能无损承载全部 12 声道的编码** |
| AAC-LC / MP3 | 6 / 2 | 兜底，触发时在底部栏警告 |

#### 一个重要的发现：ffmpeg 会「成功但静默降混」

我最初只检查退出码，结果 TrueHD 输出了 5.0 而不是 12 声道——**退出码 0，但声道少了一半**。
E-AC-3 和 DTS 同样会静默降为 5.0，ALAC 会变成 7 声道。

因此加了 **编码后声道校验**：读回实际声道数，不符就**显式指定 `-ac` 重试**，仍不符才降档。
这一步是必须的——没有它，降级梯会停在第一个"看起来成功"的档位上，交给你一个残缺的混音。

#### 底部栏警告

降级（降混声道 / 用到底部兜底编码）时，界面底部会显示琥珀色警告，同时写入日志：

```
Dolby TrueHD：12 声道降混为 6。ffmpeg 的 TrueHD 编码器实测上限 6 声道（5.1）；
需 Matroska 容器，Windows Media Player 不支持
```

## 四、已知限制

1. **Dolby Atmos 做不出来**：ffmpeg 无法写入对象音频元数据。E-AC-3 只是载体，输出的是 DD+ 而非真 Atmos。
2. **DTS-HD MA 做不出来**：ffmpeg 没有该编码器，`dca` 产出的是有损 DTS 核心。
3. **TrueHD / DTS 用的是实验性编码器**（需 `-strict -2`），且上限只有 6 声道。
4. **FLAC 上限 8 声道**，12 声道沉浸声会被降混；唯一能全声道承载的是 WavPack。
5. **随附的 ffmpeg 是 GPLv3**：以独立进程调用属"聚合"，NcmForge 自身不必被传染，但再分发需保留许可证并提供源码获取方式。**不需要时删掉 `tools/ffmpeg/` 即可。**
6. 本批 18 个真实样本中没有 E-AC-3 / PCM 负载，这两条路径用合成容器验证。
7. `libfdk_aac` 在常见构建中不可用，AAC 用 ffmpeg 原生编码器。

## 六、快速命令速查

```bash
# 看本机 ffmpeg 能力（解码器 / 硬件编码器 / AVS3 支持 / 文件位置）
ncmforge doctor

# 沉浸声 → 按降级梯自动选最佳编码（会优先尝试 TrueHD）
ncmforge convert immersive.ncm --format auto --reencode

# 沉浸声 → 保留全部 12 声道（无损，唯一不降混的选择）
ncmforge convert immersive.ncm --format auto --reencode --surround preserve   # 落到 WavPack

# 沉浸声 → AAC-LC 5.1（兼容性最好，通用播放器都能放）
ncmforge convert immersive.ncm --format auto --reencode --surround 51

# 沉浸声 → 原样无损提取（不转码，保留原始容器）
ncmforge convert immersive.ncm --format copy

# 普通文件 → MP3 / FLAC
ncmforge convert song.ncm --format mp3 --bitrate 320
ncmforge convert song.ncm --format flac
```

发布：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1 -FfmpegDir "D:\ffmpeg-avs" -FfmpegInCli
powershell -ExecutionPolicy Bypass -File scripts\make-icon.ps1
```
